---
title: "Get Roadmap Info"
api: "POST /v1/public/roadmap.info"
description: "Get roadmap with all stages and their topics. Returns public stages only with organized topic data."
---

## Authentication

```bash
Authorization: Bearer YOUR_API_KEY
```

## Request Body

<ParamField body="feedback" type="boolean">
  Filter for feedback roadmap (true) or feature roadmap (false). Optional.
</ParamField>

<ParamField body="sort" type="string" default="createdAt">
  Field to sort topics by (createdAt, updatedAt, title)
</ParamField>

<ParamField body="direction" type="string" default="DESC">
  Sort direction (ASC or DESC)
</ParamField>

## Response

<ResponseField name="data" type="object">
  Roadmap object
</ResponseField>

<ResponseField name="stages" type="array">
  Array of public stage objects
</ResponseField>

<ResponseField name="stageTopics" type="object">
  Topics grouped by stage ID
  <Expandable title="Structure">
    <ResponseField name="[stageId]" type="array">Array of topic objects for this stage</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="team" type="object">
  Team information
</ResponseField>

<ResponseField name="pagination" type="object">
  Pagination metadata
</ResponseField>

```python Python
import requests

response = requests.post(
    'https://api.userorbit.com/v1/public/roadmap.info',
    headers={
        'Authorization': 'Bearer YOUR_API_KEY',
        'Content-Type': 'application/json'
    },
    json={
        'feedback': False,
        'sort': 'createdAt',
        'direction': 'DESC'
    }

result = response.json()
roadmap = result['data']

stage_topics = result['stageTopics']
```

## Behavior

- **Public Only**: Returns only stages marked as public (`isPrivate: false`)
- **Roadmap Type**: Filters by feedback flag if provided
- **Organized Data**: Topics pre-grouped by stage for easy rendering
- **Pagination**: Topics paginated within each stage

## Use Cases

- **Public Roadmap Display**: Show complete roadmap to users
- **Kanban View**: Display stages as columns with topics as cards
- **Roadmap Widget**: Embed roadmap in external sites

## Notes

- Private stages are filtered out automatically
- Topics include vote and comment counts
- Stage topics are already grouped by stageId for convenience
- Returns first roadmap if multiple exist (filtered by feedback flag)
