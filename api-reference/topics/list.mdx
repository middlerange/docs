---
title: "List Topics"
api: "POST /v1/public/topics.list"
description: "Get all published topics from a specific roadmap stage. Used for displaying public roadmap."
---

## Authentication

This endpoint requires API key authentication via the `Authorization` header.

```bash
Authorization: Bearer YOUR_API_KEY
```

## Request Body

<ParamField body="roadmapId" type="string" required>
  UUID of the roadmap to fetch topics from
</ParamField>

<ParamField body="stageId" type="string" required>
  UUID of the stage within the roadmap
</ParamField>

<ParamField body="sort" type="string" default="createdAt">
  Field to sort by (e.g., "createdAt", "updatedAt", "title")
</ParamField>

<ParamField body="direction" type="string" default="DESC">
  Sort direction: `ASC` or `DESC`
</ParamField>

<ParamField body="offset" type="number" default="0">
  Number of records to skip
</ParamField>

<ParamField body="limit" type="number" default="10">
  Maximum number of records to return
</ParamField>

## Response

<ResponseField name="data" type="array">
  Array of topic objects
  <Expandable title="Topic Object">
    <ResponseField name="id" type="string">Topic ID (UUID)</ResponseField>
    <ResponseField name="title" type="string">Topic title</ResponseField>
    <ResponseField name="content" type="string">Topic description/content</ResponseField>
    <ResponseField name="status" type="string">published or draft</ResponseField>
    <ResponseField name="roadmapId" type="string">Parent roadmap ID</ResponseField>
    <ResponseField name="stageId" type="string">Parent stage ID</ResponseField>
    <ResponseField name="votesCount" type="number">Number of upvotes</ResponseField>
    <ResponseField name="commentsCount" type="number">Number of comments</ResponseField>
    <ResponseField name="created_at" type="string">Creation timestamp</ResponseField>
    <ResponseField name="updated_at" type="string">Last update timestamp</ResponseField>
    <ResponseField name="author" type="object">Creator subscriber info</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pagination" type="object">
  <Expandable title="properties">
    <ResponseField name="offset" type="number">Current offset</ResponseField>
    <ResponseField name="limit" type="number">Current limit</ResponseField>
  </Expandable>
</ResponseField>

## Use Cases

- **Public Roadmap**: Display roadmap stages with topics
- **Feature Timeline**: Show planned/completed features
- **Status Updates**: Communicate product progress
- **Community Engagement**: Allow users to see and vote on features

## Notes

- Only returns **published** topics (draft topics are hidden)
- Topics must belong to the specified roadmap and stage
- Includes vote and comment counts for engagement metrics
- Supports pagination for large roadmaps
