---
title: "Get Subscriber Info"
api: "POST /v1/public/subscriber.info"
description: "Get information about the currently authenticated subscriber."
---

## Authentication

Requires subscriber JWT token from login/identify.

```bash
Authorization: Bearer SUBSCRIBER_JWT_TOKEN
```

## Request Body

This endpoint does not require any request body parameters.

## Response

<ResponseField name="data" type="object">
  Subscriber object with full details
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      Subscriber ID (UUID)
    </ResponseField>
    <ResponseField name="name" type="string">
      Subscriber's name
    </ResponseField>
    <ResponseField name="email" type="string">
      Subscriber's email
    </ResponseField>
    <ResponseField name="source" type="string">
      Source of creation
    </ResponseField>
    <ResponseField name="meta" type="object">
      Custom metadata
    </ResponseField>
    <ResponseField name="avatarUrl" type="string">
      Avatar URL if available
    </ResponseField>
    <ResponseField name="createdAt" type="string">
      Account creation timestamp
    </ResponseField>
    <ResponseField name="lastUpdated" type="string">
      Last update timestamp
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl --location --request POST 'https://api.yourapp.com/v1/public/subscriber.info' \
--header 'Authorization: Bearer SUBSCRIBER_JWT_TOKEN' \
--header 'Content-Type: application/json'
```

```javascript Node.js
const response = await fetch('https://api.yourapp.com/v1/public/subscriber.info', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer SUBSCRIBER_JWT_TOKEN',
    'Content-Type': 'application/json'
  }
});

const data = await response.json();
```

```python Python
import requests

response = requests.post(
    'https://api.yourapp.com/v1/public/subscriber.info',
    headers={
        'Authorization': 'Bearer SUBSCRIBER_JWT_TOKEN',
        'Content-Type': 'application/json'
    }
)

data = response.json()
```

## Use Cases

- Get current user profile information
- Display user details in widget
- Check authentication status

## Notes

- Requires valid JWT token
- Returns 401 if token is invalid or expired
