---
title: "Vote on Topic"
api: "POST /v1/public/topic-votes.create"
description: "Cast an upvote on a topic (feature request). Requires subscriber authentication."
---

## Authentication

```bash
Authorization: Bearer SUBSCRIBER_JWT_TOKEN
```

## Request Body

<ParamField body="id" type="string" required>
  Topic ID (UUID) to vote on
</ParamField>

## Response

<ResponseField name="data" type="object">
  Created vote object
  <Expandable title="properties">
    <ResponseField name="id" type="string">Vote ID</ResponseField>
    <ResponseField name="topicId" type="string">Topic ID</ResponseField>
    <ResponseField name="creatorId" type="string">Subscriber ID</ResponseField>
    <ResponseField name="createdAt" type="string">Vote timestamp</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl --location --request POST 'https://api.yourapp.com/v1/public/topic-votes.create' \
--header 'Authorization: Bearer SUBSCRIBER_JWT_TOKEN' \
--header 'Content-Type: application/json' \
--data-raw '{
  "id": "topic-uuid-123"
}'
```

```javascript Node.js
const response = await fetch('https://api.yourapp.com/v1/public/topic-votes.create', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${subscriberToken}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ id: topicId })
});

const { data } = await response.json();
```

</RequestExample>

<ResponseExample>

```json Response
{
  "data": {
```

</ResponseExample>

## Error Responses

```json Not Authenticated
{
  "error": "Bad request"
}
```

```json Already Voted
{
  "error": "Duplicate vote"
}
```

## Behavior

- **One Vote Per Subscriber**: Each subscriber can only vote once
- **Database Constraint**: Prevents duplicate votes

## Notes

- Requires subscriber authentication
- Returns error if already voted
- Vote immediately visible in count
