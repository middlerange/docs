---
title: "Unsubscribe from Topic"
api: "POST /v1/public/topics.unsubscribe"
description: "Unsubscribe from notifications for a topic."
---

## Authentication

```bash
Authorization: Bearer SUBSCRIBER_JWT_TOKEN
```

## Request Body

<ParamField body="id" type="string" required>
  Topic ID (UUID) to unsubscribe from
</ParamField>

## Response

<ResponseField name="data" type="object">
  Unsubscription result
  <Expandable title="properties">
    <ResponseField name="ok" type="boolean">Always true</ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl --location --request POST 'https://api.yourapp.com/v1/public/topics.unsubscribe' \
--header 'Authorization: Bearer SUBSCRIBER_JWT_TOKEN' \
--header 'Content-Type: application/json' \
--data-raw '{
  "id": "topic-uuid-123"
}'
```

```javascript Node.js
const response = await fetch('https://api.yourapp.com/v1/public/topics.unsubscribe', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${subscriberToken}`,
    'Content-Type': 'application/json'
  },

```

</RequestExample>

<ResponseExample>

```json Response
{
```

</ResponseExample>

## Behavior

- **Event Trigger**: Fires `topic-subscribers.delete` event
- **Idempotent**: Safe to call even if not subscribed

## Notes

- Stops all notifications for this topic
- Returns success even if subscription didn't exist
