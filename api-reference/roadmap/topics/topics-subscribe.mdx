---
title: "Subscribe to Topic"
api: "POST /v1/public/topics.subscribe"
description: "Subscribe to notifications for a topic. Get notified of comments, votes, and status changes."
---

## Authentication

```bash
Authorization: Bearer SUBSCRIBER_JWT_TOKEN
```

## Request Body

<ParamField body="id" type="string" required>
  Topic ID (UUID) to subscribe to
</ParamField>

## Response

<ResponseField name="data" type="object">
  Subscription result
  <Expandable title="properties">
    <ResponseField name="topicSubscriber" type="object">Topic subscription record</ResponseField>
    <ResponseField name="ok" type="boolean">Always true</ResponseField>
  </Expandable>
</ResponseField>

## Behavior

- **Event Trigger**: Fires `topic-subscribers.create` event
- **Team Validation**: Subscriber must belong to same team
- **Idempotent**: Safe to call multiple times

## Notes

- Triggers webhook event for integrations
- Subscriber receives notifications for topic updates
