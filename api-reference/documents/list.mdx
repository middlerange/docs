---
title: "List Documents"
api: "POST /v1/public/documents.list"
description: "Get published documents from your knowledge base. Supports filtering by collection and full-text search."
---

## Authentication

This endpoint requires API key authentication via the `Authorization` header.

```bash
Authorization: Bearer YOUR_API_KEY
```

## Request Body

<ParamField body="collectionId" type="string">
  UUID of collection to filter by (optional)
</ParamField>

<ParamField body="search" type="string">
  Search query for full-text search on title and content (optional)
</ParamField>

<ParamField body="sort" type="string" default="publishedAt">
  Field to sort by (e.g., "publishedAt", "updatedAt", "title")
</ParamField>

<ParamField body="direction" type="string" default="DESC">
  Sort direction: `ASC` or `DESC`
</ParamField>

<ParamField body="offset" type="number" default="0">
  Number of records to skip
</ParamField>

<ParamField body="limit" type="number" default="10">
  Maximum number of records to return
</ParamField>

## Response

<ResponseField name="data" type="array">
  Array of document objects
  <Expandable title="Document Object">
    <ResponseField name="id" type="string">Document ID (UUID)</ResponseField>
    <ResponseField name="title" type="string">Document title</ResponseField>
    <ResponseField name="text" type="string">Document content (markdown/text)</ResponseField>
    <ResponseField name="urlId" type="string">Short URL identifier</ResponseField>
    <ResponseField name="url" type="string">URL path</ResponseField>
    <ResponseField name="collectionId" type="string">Parent collection ID</ResponseField>
    <ResponseField name="teamId" type="string">Team ID</ResponseField>
    <ResponseField name="publishedAt" type="string">Publication timestamp</ResponseField>
    <ResponseField name="createdAt" type="string">Creation timestamp</ResponseField>
    <ResponseField name="updatedAt" type="string">Last update timestamp</ResponseField>
    <ResponseField name="visits" type="number">View count</ResponseField>
    <ResponseField name="pinnedById" type="string">ID of user who pinned (if pinned)</ResponseField>
    <ResponseField name="createdBy" type="object">Document creator</ResponseField>
    <ResponseField name="reactions" type="object">Reaction counts</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pagination" type="object">
  Pagination metadata
</ResponseField>

<ResponseField name="subscriber" type="object">
  Current subscriber info (if authenticated)
</ResponseField>

<ResponseField name="team" type="object">
  Team information
</ResponseField>

## Search Behavior

- Searches both **title** and **text** fields
- Case-insensitive matching
- Partial word matching supported
- Returns results ranked by relevance

## Use Cases

- **Knowledge Base**: Display help articles
- **Documentation Portal**: Public API docs
- **Help Center**: Customer support articles
- **Changelog**: Product updates and announcements

## Notes

- Only returns **published** documents (unpublished are hidden)
- Pinned documents appear first regardless of sort
- Search query is optional (omit to get all documents)
- Visit count tracks document popularity
- Supports emoji reactions if enabled
